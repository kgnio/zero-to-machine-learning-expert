============================================================
1. MACHINE LEARNING FUNDAMENTALS
============================================================

Artificial Intelligence (AI):
Systems designed to perform tasks associated with human intelligence.

Machine Learning (ML):
Methods that learn patterns or relationships from data.

Dataset:
A collection of observations used for analysis or learning.

Sample:
One observation in a dataset.

Feature (X):
An input variable used by a model.

Target (y):
The value that a supervised learning model attempts to predict.

Model:
A mathematical or computational function that maps inputs to outputs.

Prediction (y_hat):
The output produced by a model.

Training:
The process of learning model parameters from data.

Inference:
Using a model to generate predictions.

Parameter:
A model value learned or adjusted during training.

Hyperparameter:
A configuration value chosen outside the parameter-learning process.

Weight:
A parameter controlling the contribution of an input.

Bias:
An additive parameter in a model.

Supervised Learning:
Learning from examples with known target values.

Rule-Based Programming:
Executing explicitly defined rules without learning them from data.

KEY DISTINCTION:
A fixed formula is not automatically a trained ML model.
Learning model parameters from data is what makes the
gradient descent example a machine learning experiment.

Algorithm:

7. CALCULUS AND OPTIMIZATION
============================================================

Function:
A mapping from inputs to outputs.

Derivative:
The instantaneous rate of change of a function.

Partial Derivative:
A derivative with respect to one variable while
other variables are held constant.

Gradient:
A vector of partial derivatives.

Loss Function:
A function measuring prediction error.

Mean Squared Error (MSE):
The mean of squared prediction errors.

Gradient Descent:
An optimization method that moves parameters
opposite the gradient.

Learning Rate:
The step size used during parameter updates.

Epoch:
One complete pass through the training dataset.

Optimization:
Improving an objective by adjusting parameters.

LINEAR REGRESSION:

y_hat = w * x + b

MSE:

MSE = mean((y_hat - y) ** 2)

GRADIENTS FOR SINGLE-FEATURE LINEAR REGRESSION:

dL/dw = 2 * mean(x * (y_hat - y))
dL/db = 2 * mean(y_hat - y)

PARAMETER UPDATES:

w_new = w_old - learning_rate * dL/dw
b_new = b_old - learning_rate * dL/db

REMEMBER:

The gradient indicates the direction of fastest
local increase of a differentiable scalar function.

Subtracting the gradient can reduce the loss.

A learning rate that is too small may converge slowly.

A learning rate that is too large may cause divergence.

A low training loss does not guarantee good performance
on unseen data.

8. PROBABILITY AND STATISTICS
============================================================

Population:
The complete collection of observations of interest.

Sample:
A subset selected from a population.

Mean:
The arithmetic average.

Variance:
The average squared deviation from the mean
for a population.

Standard Deviation:
The square root of variance.

Probability:
A numerical measure of event likelihood.

Conditional Probability:
The probability of an event given another event.

Random Variable:
A value determined by a random outcome.

Probability Distribution:
A description of the probabilities of outcomes.

Bernoulli Distribution:
A distribution with two possible outcomes.

Normal Distribution:
A continuous symmetric bell-shaped distribution.

Random Seed:
An initialization value used for reproducible
pseudorandom generation.

Sampling Distribution:
The probability distribution of a statistic
computed from repeated samples.

Central Limit Theorem:
Under appropriate conditions, standardized sample
means approach a normal distribution as sample
size increases.

Standard Error:
The standard deviation of a sampling distribution.

IMPORTANT FORMULAS:

Mean = sum(values) / n

Population variance = sum((x - mean)^2) / n

Population standard deviation = sqrt(variance)

Sample variance = sum((x - sample_mean)^2) / (n - 1)

P(A | B) = P(A and B) / P(B), for P(B) > 0

Standard error of the mean = sigma / sqrt(n)
for independent observations with finite variance.

IMPORTANT DISTINCTIONS:

ddof=0 calculates population variance or standard
deviation using denominator n.

ddof=1 uses denominator n-1 for variance.

A sampling distribution is not the same as
the distribution of individual observations.

Larger samples generally reduce the standard
error of a sample mean.

9. MACHINE LEARNING WORKFLOW
============================================================

1. Define the prediction problem.
2. Identify features and target.
3. Inspect and validate data.
4. Separate training and test observations.
5. Fit model parameters on training data.
6. Evaluate training performance.
7. Evaluate unseen test performance.
8. Compare with a baseline.
9. Inspect errors and limitations.
10. Document results and assumptions.

IMPORTANT RULES:

Never fit a model using the test targets.

Avoid choosing a model based repeatedly on the
same final test set.

Apply data transformations carefully to prevent
information leakage.

A baseline gives context to performance metrics.

Synthetic data is useful for controlled experiments,
but it does not prove real-world reliability.

Saving random seeds improves reproducibility.
