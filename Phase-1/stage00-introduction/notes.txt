
STAGE 00 - INTRODUCTION TO MACHINE LEARNING

Artificial Intelligence (AI):
Computer systems that perform tasks associated with human intelligence.

Machine Learning (ML):
Methods that learn patterns or relationships from data.

Dataset:
A collection of data samples.

Sample:
A single observation or record in a dataset.

Feature:
An input variable used to make predictions.

Target:
The value a model is trained to predict.

Model:
A mathematical or computational function used to make predictions.

Prediction:
The output generated by a model for a given input.

Parameter:
A value that controls the behavior of a model.

Training:
The process of learning model parameters from data.

Coefficient:
A numerical factor that multiplies a variable.

Rule-Based System:
A system that follows explicitly defined rules.
