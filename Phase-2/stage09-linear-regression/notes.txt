
STAGE 09 - LINEAR REGRESSION

Linear Regression:
A supervised learning method for predicting numerical targets
using a linear combination of input features.

Simple Linear Regression:
Linear regression using one input feature.

Multiple Linear Regression:
Linear regression using multiple input features.

Coefficient:
A learned parameter representing a feature's contribution
to a linear prediction, holding other features fixed.

Intercept:
The predicted value when all input features equal zero.

Prediction:
The output generated by a trained model.

Training:
The process of fitting model parameters to training data.

Inference:
Generating predictions with an already trained model.

Ordinary Least Squares:
A method that minimizes the sum of squared residuals.

Model.fit():
A Scikit-learn method that learns model parameters from data.

Model.predict():
A Scikit-learn method that generates predictions.

Mean Absolute Error (MAE):
The average absolute difference between actual and
predicted values.

Mean Squared Error (MSE):
The average squared difference between actual and
predicted values.

Root Mean Squared Error (RMSE):
The square root of MSE.

R-Squared (R2):
A regression score comparing squared prediction error
with a mean-target baseline.

Residual:
The difference between an observed target and its prediction.

Baseline Model:
A simple reference model used for performance comparison.

Generalization:
The ability of a trained model to perform on unseen data.

Underfitting:
A model failing to capture important patterns in the data.

Overfitting:
A model learning training-specific patterns that do not
generalize sufficiently to new data.

Feature Coefficient Interpretation:
The expected change in a linear model's prediction from a
one-unit feature increase when other features stay fixed.

Correlation vs Causation:
Statistical association does not necessarily establish
a causal relationship.

Extrapolation:
Predicting outside the input range represented by training data.

KEY FORMULAS:

Simple Linear Regression:
y_hat = weight * x + bias

Multiple Linear Regression:
y_hat = X @ weights + bias

MAE:
mean(abs(y - y_hat))

MSE:
mean((y - y_hat) ** 2)

RMSE:
sqrt(MSE)

R2:
1 - sum((y - y_hat) ** 2) / sum((y - mean(y)) ** 2)

Residual:
y - y_hat

KEY RULES:

Fit the model using training data only.

Do not train the model on test targets.

Evaluate regression models using appropriate metrics.

MAE and RMSE use the same units as the target.

MSE uses squared target units.

R2 can be negative.

Compare model performance against a baseline.

Inspect residuals to identify patterns in prediction errors.

A good training score does not guarantee generalization.

Coefficients do not automatically establish causation.

Coefficients with different feature units should not
be directly ranked by magnitude.

A model trained on historical data is not automatically
reliable for current real-world predictions.
